# 클립 전송기

**PC에서 만든 카드뉴스를 휴대폰으로 보내서, 네이버 클립에 바로 올릴 수 있게 해주는 Windows 프로그램**이에요.

휴대폰으로 QR만 찍으면 카드뉴스 이미지를 갤러리에 저장하고, 제목과 태그가 든 글을 복사할 수 있어요.

**준비물**: Windows PC, 안드로이드 휴대폰, 같은 와이파이

## 이렇게 써요

**PC에서**

1. 받은 `clip-sender.exe`를 바탕화면이나 문서 안의 **새 폴더**에 넣고 **더블클릭**해요. (다운로드 폴더에 그대로 두지 마세요) 처음에는 아래 [처음 실행할 때 나오는 화면](#처음-실행할-때-나오는-화면)이 나올 수 있어요.
2. 브라우저에 프로그램 화면이 열려요. 처음에는 **암호를 한 번 만들어요.** 휴대폰에서 열 때 쓰는 암호예요.
3. **카드뉴스 폴더 열기**를 눌러 폴더를 열고, 카드뉴스 ZIP 파일을 넣어요. 몇 초 뒤 목록에 나타나요.

**휴대폰에서**

4. PC 화면의 **QR을 휴대폰 카메라로 찍어요.** (PC와 휴대폰이 같은 와이파이에 있어야 해요) 처음 한 번만 암호를 입력해요.
5. 목록에서 카드뉴스를 눌러요. **N장 한 번에 받기**를 누르면 이미지가 갤러리에 저장되고, **클립용 복사**를 누르면 제목과 태그가 든 글이 복사돼요.
6. 네이버 클립 앱을 열어서 갤러리의 이미지를 고르고, 복사한 글을 붙여넣어요.

> 네이버 클립 휴대폰 앱은 태그를 5개까지만 쓸 수 있어서, **클립용 복사**는 태그를 5개로 맞춰줘요. 꼭 붙일 태그는 프로그램 설정에서 정할 수 있어요.

## 처음 실행할 때 나오는 화면

서명하지 않은 프로그램이라 처음에는 Windows가 경고 화면을 보여줘요. 아래 순서대로 누르면 돼요.

### 1단계 · 추가 정보 누르기

"Windows의 PC 보호" 화면이 나오면, 빨간 네모 안의 **추가 정보**를 눌러요.

![1단계: 추가 정보 누르기](step1.png)

### 2단계 · 실행 누르기

앱 정보가 나오면, 빨간 네모 안의 **실행**을 눌러요.

![2단계: 실행 누르기](step2.png)

### 3단계 · 액세스 허용 누르기

방화벽 알림이 나오면, **개인 네트워크**만 체크된 상태로 **액세스 허용**을 눌러요. 휴대폰으로 열 때 꼭 필요해요.

![3단계: 액세스 허용 누르기](firewall.png)

> 받을 때 브라우저가 "위험할 수 있다"고 알려주면, 다운로드 목록의 `...` 메뉴에서 **유지**를 눌러요.

## 휴대폰에서 안 열려요

아래를 순서대로 확인해보세요.

1. **PC와 휴대폰이 같은 와이파이인가요?** 휴대폰이 데이터(LTE/5G)나 다른 와이파이에 연결돼 있으면 열리지 않아요.
2. **PC에서 프로그램이 켜져 있나요?** PC 화면(브라우저 창)을 닫으면 프로그램도 꺼져요. 휴대폰으로 쓰기 전에 PC에서 켜 두세요.
3. **방화벽에서 허용했나요?** 위 3단계를 놓쳤다면 Windows의 방화벽 설정에서 `clip-sender.exe`를 **개인 네트워크**로 허용해요. (메뉴 이름은 Windows 버전에 따라 조금 달라요)
4. **QR을 다시 찍어보세요.** 공유기가 주소를 바꾸면 예전에 저장해 둔 주소는 안 열릴 수 있어요.
5. **삼성 인터넷을 쓰고 있나요?** 이미지를 받을 때마다 묻는 창이 떠요. 화면에 나오는 **크롬으로 열기**를 누르면 한 번에 저장돼요.

---

## 안심하고 쓰세요

- 카드뉴스와 글은 **PC 안에만** 저장돼요. 인터넷으로 올리지 않아요.
- 휴대폰과는 **같은 와이파이 안에서만** 주고받아요. 밖에서는 열리지 않고, 열 때 암호가 필요해요.
- 인터넷은 새 버전을 확인하고 받을 때만 GitHub에 접속해요.
- 지우고 싶으면 `clip-sender.exe`를 지우고, `내 문서\클립 전송기` 폴더와 `%LOCALAPPDATA%\ClipSender` 폴더를 지우면 돼요. (탐색기 주소창에 `%LOCALAPPDATA%\ClipSender`를 붙여넣으면 열려요)

## 자주 묻는 질문

<details>
<summary>카드뉴스 ZIP에는 뭐가 들어 있어야 하나요?</summary>

이미지(png, jpg, webp)가 하나 이상 들어 있어야 해요. 제목·본문·해시태그를 적은 텍스트 파일(.txt)이 함께 있으면 글이 자동으로 정리되고, 없으면 화면에서 직접 붙여넣을 수 있어요.
</details>

<details>
<summary>같은 ZIP을 또 넣으면 어떻게 되나요?</summary>

이미 가져온 ZIP이면 화면 맨 위에 "새 카드뉴스로 또 가져올까요?"라고 물어봐요. 이름만 같고 내용이 다르면 물어보지 않고 새 카드뉴스로 가져와요.
</details>

<details>
<summary>카드뉴스를 삭제하면 어떻게 되나요?</summary>

목록 위의 **정리**로 여러 개를 골라 지우거나, 카드뉴스를 열어 맨 아래에서 지울 수 있어요. 이미지는 지워지지만 제목·메모·날짜 기록은 **히스토리**에 남고, 원본 ZIP은 `가져온 ZIP` 폴더에 그대로 있어요.
</details>

<details>
<summary>프로그램은 어떻게 끄나요?</summary>

PC 화면 위쪽의 **종료**를 누르거나 브라우저 창을 닫으면 돼요.
</details>

<details>
<summary>사용법은 어디서 보나요?</summary>

프로그램 화면 위쪽 **도움말**에 있어요.
</details>
