# 클립 전송기

카드뉴스 ZIP 파일을 폴더에 넣으면 자동으로 정리해주고,
폰으로 이미지를 받고 클립에 올릴 글을 복사할 수 있게 해주는 Windows 프로그램이에요.

## 설치
1. 오른쪽 **Releases**에서 최신 버전의 `clip-sender.exe`를 받아요.
2. 바탕화면이나 문서 안에 새 폴더를 만들고 그 안에 넣어요. (다운로드 폴더에 그대로 두지 마세요)
3. `clip-sender.exe`를 더블클릭해요. 브라우저에 프로그램 화면이 열려요.

## Windows 보안 화면이 나오면
서명하지 않은 프로그램이라 처음 실행할 때 이런 화면이 나올 수 있어요.

- **"Windows에서 PC를 보호했습니다"**: **추가 정보**를 누른 뒤 **실행**을 눌러요.
- **방화벽 알림**: 폰으로 보려면 **허용**을 눌러요. 집이나 사무실 같은 **개인 네트워크**만 체크하는 걸 권해요.

## 사용법
프로그램 화면 위쪽 **도움말**에서 볼 수 있어요.

## 문의
프로그램 위쪽 **의견 보내기**로 버그나 개선사항을 남겨주세요.
